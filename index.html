Failure Mode and Effects Analysis

RPN = Severity × Occurrence × Detection, live
Scales run 1–10. Severity is the effect on the customer or the next module, occurrence is how often the cause happens, detection is how likely current controls are to catch it before it escapes — 10 means it walks straight past you. Anything over 100 is usually worth an action; anything with severity 9–10 is worth an action regardless of RPN.

How the Numbers Are Calculated

Within-subgroup sigma — for individuals, σwithin = MR̄ / 1.128 (d₂ for n=2). For subgrouped data, σwithin = R̄ / d₂(n). This is what Cp and Cpk use, so they describe the process as it could be if it only had its short-term noise.

Overall sigma — the plain sample standard deviation across every point in the filter. Pp and Ppk use this, so they describe the process as the customer actually received it, drift included. A wide Cpk-to-Ppk gap means the process moved during the period; a narrow gap means it sat still.

Control limits — I chart: X̄ ± 3σwithin. MR chart: UCL = D₄·MR̄ with D₄ = 3.267, LCL = 0. X̄ chart: X̅ ± A₂R̄. R chart: D₃R̄ and D₄R̄. Constants come from the standard d₂/A₂/D₃/D₄ table for n = 2…25.

EWMA — zᵢ = λxᵢ + (1−λ)zᵢ₋₁ with limits X̄ ± Lσ√(λ/(2−λ)·(1−(1−λ)²ⁱ)), so the limits widen out from the start-up value rather than being flat.

CUSUM — standardized tabular form: SH = max(0, SH₋₁ + zᵢ − k), SL = max(0, SL₋₁ − zᵢ − k), signalling past ±h. Defaults k = 0.5, h = 5 detect a 1σ shift in about 10 points.

PPM and sigma level — theoretical PPM integrates the normal tails beyond each limit using overall σ. Observed PPM just counts real out-of-spec rows, which is the honest number when the distribution is skewed — Ioff and Igate usually are. Sigma level is Zbench + 1.5 to follow the usual shift convention.

Yield — a die passes when every mapped parameter is inside its limits. If a bin column is mapped, bin 1 is treated as pass and the bin-based yield is reported alongside.

Reading the rule counts honestly — the run rules were written for charts of 25–50 subgroup points. Run them on 9,000 per-die measurements and rules 2, 6 and 8 fire at a high rate by construction: a run of 9 on one side is common in that much data, and it gets commoner still when the parameter is skewed, which Ioff and Igate always are and Rc and Idsat usually are because of their radial component. Rule 1 stays trustworthy at any n. For lot-level control, set the subgroup to By wafer and read the X̄ chart — one point per wafer is the unit the rules were designed for.
